# Weather Fit

**오늘 날씨를 "무엇을 입을지" 하나의 결정으로 번역하는 남성 코디 가이드.**
서버도 API 키도 없이, 브라우저만으로 도는 정적 PWA입니다.

### 👉 **[바로 사용하기 — moriochoradio.github.io/weather-fit](https://moriochoradio.github.io/weather-fit/)**

---

## 무엇을 하는 앱인가

| 영역 | 내용 |
|---|---|
| **코디 추천** | 4개 스타일(올드머니·캐주얼·포멀·미니멀) × 6단계 기온대에 맞춘 **코디 75벌**. 상의·하의·신발·아우터·포인트와 착장 팁, "조용한 포인트" 한 줄 |
| **옷 실루엣** | 코디 문구에 맞는 옷 모양에 **실제 색을 칠한 SVG 실루엣** + 팔레트. 글자만으로는 감이 오지 않는 문제에 대한 답 |
| **지역** | 전국 **161곳** (10개 권역). 지역명·권역명 검색, 즐겨찾는 지역 빠른 전환 |
| **날씨** | 체감·강수·바람·습도·UV, 시간별 기온·강수 그래프, 내일 미리보기, 주간 예보 |
| **상황 반영** | 체감 보정(추위/더위 탐), 일정별(출근·주말·저녁) 조정, 강수 확률 50% 이상이면 신발·소품 자동 보정 |
| **출발 시각** | 비가 오기 시작하는 시간을 읽어 지금 나갈지 알려줌 |
| **옷장 연동** | 없는 아이템을 표시하면 같은 온도 균형을 유지하는 대체 아이템 제안 |
| **주간 준비** | 앞으로 5일을 보고 방수 신발·차양 아이템·여벌 이너를 미리 꺼내둘 것으로 정리 |
| **기록** | 저장한 룩·착용 기록, JSON 파일로 내보내기·불러오기, 기기 기록 초기화 |
| **PWA** | 홈 화면 설치, 오프라인 캐시 |

## 데이터와 프라이버시

- 날씨는 [Open-Meteo](https://open-meteo.com/)를 브라우저에서 직접 호출합니다. **API 키가 필요 없고 서버를 거치지 않습니다.**
- 선택한 지역·스타일·저장한 룩·착용 기록은 **브라우저 `localStorage`에만** 저장됩니다. 서버로 전송되는 데이터가 없습니다.
- 기기를 옮길 때는 **내 기록 내려받기**로 JSON을 받아 다른 브라우저에서 불러오면 됩니다.

## 추천이 정해지는 방식

체감 기온을 6단계 기온대로 나눈 뒤, 해당 스타일·기온대·톤에 맞는 코디를 날짜 시드로 섞어 고릅니다.

| 기온대 | 한파 | 추움 | 쌀쌀 | 선선 | 따뜻 | 더움 |
|---|---|---|---|---|---|---|
| 체감 | 0° 미만 | 0–9° | 9–17° | 17–23° | 23–28° | 28° 이상 |

- **같은 날·같은 조건이면 같은 결과**가 나오고, 날짜가 바뀌면 후보 안에서 자연스럽게 돌아갑니다.
- 비 예보에는 비에 강한 코디를 앞세우고, 그래도 맞지 않으면 신발과 소품만 교체해 실루엣은 지킵니다.
- 톤 필터가 좁아 후보가 없으면 톤을, 그래도 없으면 가장 가까운 기온대로 넓혀 **빈손으로 남지 않게** 합니다.
- 날씨 API가 이상값(NaN·Infinity)을 주면 가장 더운 극단이 아니라 중간값(선선)으로 폴백합니다. 한겨울에 반팔을 추천하는 사고를 막기 위한 장치입니다.

## 기술 구성

정적 HTML·CSS·JavaScript만 배포하며 API 서버, 데이터베이스, 인증 런타임을 포함하지 않습니다. 런타임 의존성은 8개입니다.

| 의존성 | 사용처 |
|---|---|
| `react`, `react-dom` | 렌더링과 로컬 상태 |
| `wouter` | 라우팅 |
| `lucide-react` | 아이콘 |
| `@radix-ui/react-slot`, `class-variance-authority` | 버튼 변형 |
| `clsx`, `tailwind-merge` | 클래스 병합 |

번들은 앱 코드 102 kB(gzip 31 kB) + 벤더 240 kB(gzip 75 kB) + CSS 47 kB(gzip 11 kB)입니다.

## 로컬 실행

```bash
pnpm install
pnpm dev
```

검증 명령:

```bash
pnpm check   # 타입 검사
pnpm test    # Vitest 79개
pnpm build   # 프로덕션 정적 번들
```

## 배포

`main`에 푸시하면 [`.github/workflows/deploy-pages.yml`](./.github/workflows/deploy-pages.yml)이 타입 검사 → 테스트 → 빌드를 거쳐 GitHub Pages로 배포합니다. 운영비는 들지 않습니다.

Pages 경로(`/weather-fit/`)는 빌드 시 `GITHUB_PAGES=true`로 결정되고, 코드는 `import.meta.env.BASE_URL`만 참조하므로 저장소 이름을 바꿔도 따라갑니다.
