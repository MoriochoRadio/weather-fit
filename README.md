# WeatherFit — 오늘의 코디

오늘 날씨에 맞춰 남성 패션 코디를 추천하는 웹앱.
20대 후반 남성, **올드머니 · 캐주얼 · 포멀 · 미니멀** 스타일 기준.

**▶ 사용하기: https://moriochoradio.github.io/weather-fit/**
(아이폰 Safari에서 열고 공유 → "홈 화면에 추가"하면 앱처럼 쓸 수 있어요.
`main`에 푸시하면 GitHub Actions가 테스트 후 자동 배포합니다.)

## 주요 기능

- 현재 위치(권한 허용 시) 또는 **전국 시·군 선택**(17개 시·도, 161개 지역 내장)으로 오늘 날씨 표시 — 기온·체감·최저/최고·강수확률·바람·**미세먼지·자외선지수**. 한국 전용이라 지오코딩 API 의존이 없다
- 미세먼지 나쁨·자외선 높음 등 위험 수준이면 **마스크·자외선 차단 조언**을 함께 표시 (미세먼지 조회가 실패해도 날씨 표시는 그대로 동작)
- **즐겨찾는 지역**을 여러 곳 저장해 원클릭으로 전환 — 시·군보다 세밀한 지점(역·동 등)도 등록 가능
- 마지막으로 고른 **스타일·톤 필터를 기억**해 재방문 시 그대로 이어서 볼 수 있음
- 아이폰 홈 화면에 추가하면 스크린샷이 아니라 **전용 앱 아이콘**으로 표시
- **내일 예보 미리보기**(오늘 대비 기온 차이·비 소식) 한 줄 제공
- **오프라인 지원**: 마지막으로 본 날씨·코디를 캐시해 신호가 끊겨도 볼 수 있고, 오프라인 상태를 안내
- 마음에 든 코디를 **즐겨찾기에 저장**해 스타일/톤/기온 필터와 무관하게 다시 볼 수 있음
- 오늘의 코디를 **이미지 카드로 공유** — 실루엣·아이템·팁·색 팔레트를 담은 한 장짜리 PNG (이미지 공유가 안 되는 환경은 텍스트 공유 → 클립보드 복사로 자동 폴백)
- **어제와 비교** 한 줄 — "어제보다 6° 낮아요, 한 겹 더 챙기세요"처럼 실제로 옷 고를 때 쓰는 기준으로 안내
- **이번 주 예보**: 앞으로 6일의 최고/최저와 기온대(한파~더움), 비 소식을 접었다 펼 수 있게 제공
- **다른 코디 보기**: 같은 날 안에서도 추천 순서를 다시 섞어 선택지를 넓힘
- **입은 기록**: "오늘 이거 입었어요"를 눌러 두면 최근에 입은 코디는 다음 추천에서 뒤로 밀리고, 며칠 전에 입었는지 카드에 표시
- **가진 옷 체크**: 용어 풀이에서 "이건 없어요"를 눌러 두면 다음부터 그 아이템은 대체제를 앞세워 보여줌
- 아침에 보든 저녁에 보든 **남은 시간 기준**으로 추천 — 밤에 한낮 최고기온 기준 옷을 권하지 않음
- 코디는 **차분한 쿨톤**(네이비·차콜·그레이·아이스블루) 위주 + **웜톤**(캐멀·버건디·베이지)도 병행 — `전체/쿨톤/웜톤` 필터로 골라 볼 수 있고, 코디마다 "조용한 포인트" 한 곳을 명시
- **일일 브리핑**: 시간별 예보로 하루 흐름을 분석 — "아침 24° → 낮 31° → 저녁 27°" + 기온 스파크라인 + "오후 2시~6시 비 — 우산 챙기세요" 같은 행동 조언
- 아이템마다 **아이콘**(반팔/긴팔/코트/패딩/반바지/부츠/샌들 등)으로 어떤 옷인지 한눈에 구분
- 상의·하의·아우터·신발의 **실제 색을 옷 모양에 칠한 미니 실루엣**으로, 입어보기 전에도 색 조합이 한눈에 와닿게 표시
- 날씨를 종합한 **코디 추천**: 기온대 6단계 × 스타일 4종, 조합마다 2벌 이상
- 비·눈·폭염·한파·일교차·강풍에 대한 **날씨 대응 조언**과 우천 취약 소재 경고
- 매일 날짜 기반으로 **추천 순서가 바뀜** (같은 날은 새로고침해도 고정)
- **쉽게 풀이**: 발마칸 코트, 시어서커 같은 패션 용어를 일반인 눈높이로 설명하고, 옷장에 없을 때의 **대체제**까지 안내
- **대안 코디 더 보기**: 현재 기온대 근처("더 시원하게 / 쌀쌀하게 느껴진다면")의 코디도 추가로 제공
- iPhone Safari · PC 반응형, 다크모드 자동 대응
- 서버·API 키 불필요 (Open-Meteo 무료 API)

## 실행 방법

```bash
npm install
npm run dev      # 개발 서버 (http://localhost:5173)
npm test         # 단위 테스트
npm run build    # 프로덕션 빌드 → dist/
npm run preview  # 빌드 결과 미리보기
```

아이폰에서 쓰려면: 빌드 결과(`dist/`)를 아무 정적 호스팅(Vercel, Netlify, GitHub Pages 등)에 올리고
Safari에서 열어 **공유 → 홈 화면에 추가**하면 앱처럼 사용할 수 있습니다.

## 기술 스택

Vite + React 18 + TypeScript · 순수 CSS · Vitest · [Open-Meteo](https://open-meteo.com) (날씨/지오코딩)

코디 실루엣과 아이템 아이콘의 옷 모양은 모두 이 프로젝트에서 직접 작도한 SVG입니다 (외부 에셋·라이선스 의무 없음).
v1.7까지 쓰던 외부 에셋은 셔츠가 단추 모양으로, 정장이 후드티로 나오는 등 실제 옷과 어긋나는 문제가 있어 v1.8에서 전량 교체했습니다.
