### LLM 미사용 결정 기록

FR-17의 "LLM 등 활용"은 **룰 기반 브리핑 엔진**으로 구현 — LLM API는 키·서버가 필요해
NFR-03(키 없는 정적 앱)과 충돌하기 때문. 브리핑 출력을 문자열 배열로 분리해 두어
추후 서버리스 프록시를 통한 LLM 요약으로 교체 가능 (설계서 §12.3).

전면 교체. `ItemIcon`의 `pickIcon` 분류를 그대로 재사용해 문구에 맞는 에셋을 고르고 코디 색으로 채색.
`react-dom/server`로 실제 `OutfitCard`를 정적 렌더링해 실제 카드 레이아웃에서 검증 (M-26~M-29 재확인,
122개 단위 테스트 전부 유지). 라이선스 표기는 README에 추가.

### FR-21 — 미세먼지·자외선지수

정상 동작**하도록 격리(NFR-05 원칙 확장). `WeatherCard`에 미세먼지 등급(좋음/보통/나쁨/매우나쁨)과

### FR-27 — 코디 공유

`navigator.share` 지원 환경(모바일 브라우저, Windows Chrome/Edge 등)에서는 공유 시트를 띄우고,
미지원 환경은 `navigator.clipboard`로 텍스트를 복사 후 버튼 라벨을 일시적으로 "복사됨"으로 바꿔
피드백. 자동화 브라우저 테스트에서 `navigator.share`는 OS 네이티브 공유 시트를 띄워 자동화가
멈출 수 있어 실제 클릭 테스트는 하지 않고 코드 리뷰로 검증.
