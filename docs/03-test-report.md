### LLM 미사용 결정 기록

FR-17의 "LLM 등 활용"은 **룰 기반 브리핑 엔진**으로 구현 — LLM API는 키·서버가 필요해
NFR-03(키 없는 정적 앱)과 충돌하기 때문. 브리핑 출력을 문자열 배열로 분리해 두어
추후 서버리스 프록시를 통한 LLM 요약으로 교체 가능 (설계서 §12.3).

`react-dom/server`로 실제 `OutfitCard`를 정적 렌더링해 실제 카드 레이아웃에서 검증 (M-26~M-29 재확인,
122개 단위 테스트 전부 유지). 라이선스 표기는 README에 추가.
