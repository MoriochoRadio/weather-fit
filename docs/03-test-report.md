FR-17의 "LLM 등 활용"은 **룰 기반 브리핑 엔진**으로 구현 — LLM API는 키·서버가 필요해
NFR-03(키 없는 정적 앱)과 충돌하기 때문. 브리핑 출력을 문자열 배열로 분리해 두어
추후 서버리스 프록시를 통한 LLM 요약으로 교체 가능 (설계서 §12.3).

## 9. v1.4.1 — 실루엣 재작업 (사용자 피드백: "실루엣이 이상하다")

game-icons.net(CC BY 3.0)의 검증된 의류 벡터 에셋(티셔츠·셔츠·후디·패딩재킷·바지·첼시부츠 등)으로
전면 교체. `ItemIcon`의 `pickIcon` 분류를 그대로 재사용해 문구에 맞는 에셋을 고르고 코디 색으로 채색.
`react-dom/server`로 실제 `OutfitCard`를 정적 렌더링해 실제 카드 레이아웃에서 검증 (M-26~M-29 재확인,
122개 단위 테스트 전부 유지). 라이선스 표기는 README에 추가.

### 접근성 개선

- "지역 변경" 버튼에 `aria-expanded`/`aria-controls` 추가, 에러 상태에 `role="alert"` 추가
- `StyleTabs`에 화살표 키 이동(roving tabindex) + `aria-controls`로 연결된 `role="tabpanel"` 추가
- `RegionPicker` 열릴 때 select로 포커스 이동, Esc로 닫기, 닫히면 트리거 버튼으로 포커스 복귀
- 라이트모드 `--muted` 대비를 4.34:1 → 4.92:1(paper 기준)로 올려 WCAG AA 소형 텍스트 기준 충족, `DayBrief` 스파크라인 라벨 9px→10px
- `OutfitSilhouette`은 순수 장식(색상 미리보기)이라 `role="img"`+중복 `aria-label` 대신 `aria-hidden="true"`로 전환

### FR-20 — 즐겨찾는 지역 다중 저장

`localStorage`에 즐겨찾기 배열을 별도로 저장(`services/geo.ts`). 최초 방문 시 기본값으로
**양평역(영등포)·병점(화성, 융건릉 인근)·관저동(대전)** 세 곳을 시드 — 좌표는 위키백과·OpenStreetMap
Nominatim으로 확인한 실측값(37.52556, 126.88611 / 37.206806, 127.033111 / 36.2966447, 127.3371044).
마스트헤드에 `FavoriteBar`로 원클릭 전환 바를 추가하고, 현재 지역을 즐겨찾기에 추가/해제하는 토글을 제공.
