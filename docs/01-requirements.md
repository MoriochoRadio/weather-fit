## 1. 사용자 정의 (페르소나)

- **주 사용자**: 20대 후반 남성 직장인
- **선호 스타일**: 올드머니룩, 캐주얼, 포멀, 미니멀(깔끔함)
- **사용 환경**: 아침 출근 준비 중 아이폰(Safari), 또는 PC 브라우저
- **핵심 니즈**: "오늘 날씨에 맞는, 내 취향의 코디를 빠르게 보고 싶다"

## 2. 기능 요구사항 (FR)

| ID | 요구사항 | 우선순위 |
|---|---|---|
| FR-01 | 앱 진입 시 브라우저 위치 권한으로 현재 위치의 **오늘 날씨**(기온·체감온도·최저/최고·강수확률·강수량·바람·하늘상태)를 표시한다 | 필수 |
| FR-02 | (v1.2 개정) 위치 권한 거부/실패 시 **한국 지역 선택**(시/도 → 시/군 2단계)으로 위치를 지정할 수 있다 (기본값: 서울). 해외 도시 검색은 제공하지 않는다 | 필수 |
| FR-03 | 오늘 날씨를 종합해 **대표 코디 추천**을 즉시 보여준다 | 필수 |
| FR-04 | **스타일 카테고리**(올드머니 / 캐주얼 / 포멀 / 미니멀)를 선택해 카테고리별 코디를 볼 수 있다 | 필수 |
| FR-05 | 각 카테고리에서 날씨에 맞는 **코디를 여러 개**(2개 이상) 제공하고, 넘겨보며 비교할 수 있다 | 필수 |
| FR-06 | 각 코디는 **아이템 구성**(아우터/상의/하의/신발/액세서리)과 **스타일링 팁**을 텍스트로 제공한다 | 필수 |
| FR-07 | 강수(비/눈)·폭염·한파 등 특이 날씨 시 **날씨 대응 조언**(우산, 레이어링 등)을 표시한다 | 필수 |
| FR-08 | 선택한 도시는 브라우저(localStorage)에 저장되어 재방문 시 유지된다 | 권장 |
| FR-09 | 새로고침 버튼으로 날씨를 다시 조회할 수 있다 | 권장 |
| FR-10 | 코디에 등장하는 **패션 용어**(예: 발마칸 코트, 시어서커, 더비)를 일반인이 이해할 수 있는 **쉬운 설명**으로 풀이해 보여준다 | 필수 (v1.1) |
| FR-11 | 각 용어 풀이에 **대체제**("이 옷이 없으면 ○○로 대체")를 함께 안내한다 | 필수 (v1.1) |
| FR-12 | 현재 기온대 코디 외에 **인접 기온대의 대안 코디**("더 시원하게 / 더 따뜻하게")를 추가로 볼 수 있다 | 필수 (v1.1) |
| FR-13 | 지역 데이터는 **대한민국 전역**을 시/군 단위로 세분화해 내장한다 (17개 시·도, 광역시는 단일 지점 — 도심 구 단위는 날씨 차이가 무의미하므로) | 필수 (v1.2) |
| FR-14 | (v1.3 개정) 코디는 **차분한 쿨톤 위주**로 하되, **웜톤(캐멀·버건디 등) 코디도 병행 제공**한다. 강렬한 원색·과감한 디자인은 여전히 배제하고, 각 코디는 "조용한 포인트"를 명시한다 | 필수 (v1.2→1.3) |
| FR-15 | **톤 필터**(전체/쿨톤/웜톤)로 사용자가 직접 보고 고를 수 있다. 기본값은 전체이며 쿨톤이 먼저 정렬된다 | 필수 (v1.3) |
| FR-16 | 각 아이템에 **직관적인 아이콘**(반팔/긴팔/코트/패딩/반바지/부츠/샌들 등 구분)을 표시해 어떤 옷인지 한눈에 알 수 있게 한다 | 필수 (v1.3) |
| FR-17 | 접속 시점 날씨만이 아니라 **그날 전체 시간 흐름**(시간별 예보)을 분석해 일일 브리핑(아침→낮→저녁 기온 흐름, 비 오는 시간대, 우산 등 행동 조언)을 제공하고, 추천도 하루 전체에 적합하게 한다 | 필수 (v1.3) |
| FR-18 | 정적 호스팅으로 **배포**하여 아이폰 Safari에서 URL로 접근 가능하게 한다 (쉬운 배포·낮은 유지보수 우선) | 필수 (v1.3) |
| FR-19 | 상의·하의 등 아이템 색상을 텍스트만이 아니라 **실제 옷 모양에 칠한 시각적 미리보기**로 제공해, 입어보기 전에도 코디의 색 구성이 한눈에 와닿게 한다 | 필수 (v1.4) |

## 4. 유스케이스

### UC-1: 아침에 오늘 코디 확인 (기본 흐름)
1. 사용자가 앱에 접속한다.
2. 앱이 위치 권한을 요청하고, 허용 시 현재 위치의 오늘 날씨를 가져온다.
3. 앱이 날씨 요약과 대표 코디 추천을 표시한다.
4. 사용자가 카테고리 탭에서 다른 스타일의 코디들을 살펴본다.

### UC-2: 위치 권한 거부
1. 사용자가 위치 권한을 거부한다.
2. 앱이 저장된 도시(없으면 서울) 기준으로 날씨를 표시하고, 도시 검색 UI를 안내한다.
3. 사용자가 도시를 검색·선택하면 해당 도시 날씨와 코디로 갱신된다.

### UC-3: 비 오는 날
1. 강수확률이 높거나 강수가 예보된 날 접속한다.
2. 앱이 우산/방수 아이템 등 날씨 대응 조언을 강조 표시하고, 코디도 강수를 반영(예: 스웨이드 신발 제외)한다.

## 5. 수용 기준 (요약)

- [ ] 서울 기준, 접속 즉시 오늘 날씨와 대표 코디가 보인다.
- [ ] 4개 카테고리 각각에서 현재 날씨에 맞는 코디가 2개 이상 보인다.
- [ ] 기온대(한파/추움/쌀쌀/선선/따뜻/더움/폭염)에 따라 추천 아이템이 달라진다.
- [ ] 비 예보 시 우산 조언이 표시된다.
- [ ] iPhone 뷰포트(375px)에서 가로 스크롤 없이 사용 가능하다.
