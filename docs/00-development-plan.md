# 00. 개발 계획서 (Development Plan)

- **프로젝트명**: WeatherFit — 날씨 기반 패션 코디 추천 웹앱
- **작성일**: 2026-07-27
- **작성자**: 프로젝트 오너 (taeral04) / 개발 지원: Claude Code

## 1. 프로젝트 개요

매일 아침 "오늘 뭐 입지?"를 고민하는 시간을 줄여주는 웹앱.
사용자의 현재 위치(또는 선택한 도시)의 **오늘 날씨를 반영해 패션 코디를 추천**한다.
주 사용자는 20대 후반 남성이며, 선호 스타일은 **올드머니룩 · 캐주얼 · 포멀 · 미니멀(깔끔함)**.

## 2. 개발 방법론

**경량 반복형 개발 (Lightweight Iterative, 문서 주도)** 를 채택한다.

- 소규모 1인 프로젝트이므로 무거운 프로세스(스크럼 세리머니 등)는 배제한다.
- 대신 각 단계의 **산출물 문서를 반드시 남기고**, 단계 완료 시점마다 **의미 있는 커밋**을 만든다.
- 릴리스 후에는 요구사항 추가 → 설계 갱신 → 구현 → 테스트의 사이클을 반복한다.

### 단계별 산출물

| 단계 | 활동 | 산출물 | 형상관리 |
|---|---|---|---|
| 1. 계획 | 방법론·기술스택·일정 결정 | `docs/00-development-plan.md` | commit |
| 2. 요구사항 | 기능/비기능 요구사항 정의 | `docs/01-requirements.md` | commit |
| 3. 설계 | 아키텍처·데이터모델·룰엔진·UI 설계 | `docs/02-design.md` | commit |

| 6. 릴리스 | 사용 설명서, 배포 안내 | `README.md` | commit + tag `v1.0.0` |

## 3. 기술 스택 및 선정 사유

| 영역 | 선택 | 사유 |
|---|---|---|
| 프레임워크 | Vite + React 18 + TypeScript | 표준적인 SPA 스택, 빠른 빌드, 타입 안정성 |
| 스타일링 | 순수 CSS (CSS 변수 기반) | 의존성 최소화, 디자인 완전 제어 |
| 날씨 API | [Open-Meteo](https://open-meteo.com) | **무료 · API 키 불필요** → 키 유출 위험 없음, 정적 호스팅 가능 |
| 위치 | 브라우저 Geolocation + Open-Meteo Geocoding | 현재 위치 자동 감지 + 도시 검색 폴백 |
| 테스트 | Vitest | Vite 네이티브 테스트 러너 |
| 형상관리 | Git + GitHub (private repo) | 요구사항 |

## 4. 형상관리 규칙

- 원격 저장소: GitHub **private** 레포 (`weather-fit`)
- 브랜치: 1인 개발이므로 `main` 단일 브랜치 (trunk-based)
- 커밋 메시지: `<type>: <요약>` — type은 `docs`, `feat`, `fix`, `test`, `chore`
- 릴리스: 태그 `vX.Y.Z` (Semantic Versioning)
